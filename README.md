## Description
The project simulates a simple banking system. It includes the following classes:
* `Account`: Manages the bank account balance, deposits, and withdrawals.
* `Customer`: Manages customer details and links them to an array of `Account` objects.
* `Bank`: Manages an array of `Customer` objects.
* `Main`: Contains the ATM menu implemented using `Scanner` to test the classes interactively.
